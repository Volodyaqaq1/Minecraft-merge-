# Кубический Бестиарий: Сквиши Мёрдж ✨🦁

Увлекательная казуальная игра в жанре **Merge + Battle** для [Яндекс Игр](https://yandex.ru/games).

## 🎮 Описание

Объединяй милых кубических сквиши-существ, открывай редкие стихийные и золотые эволюции, развивай бестиарий и побеждай соперников на боевой арене!

- **90 уровней существ** — 30 оригинальных базовых созданий (от Цыпы до Древнего дракона), 30 стихийных форм и 30 сияющих золотых созданий.
- **Мёрдж-механика** — соединяй двух одинаковых питомцев → получай более сильного и ценного.
- **Боевая арена** — собирай непобедимую команду из 3 бойцов, круши защитные барьеры и побеждай соперников.
- **Экономика и инкубатор** — монеты, кристаллы, уровни игрока, динамические множители и таймерные яйца с наградами.
- **Бестиарий** — полная иллюстрированная коллекция всех открытых существ и их форм.

## 🛠️ Технологии

- [Phaser 3.8](https://phaser.io/)
- Vanilla JavaScript (ES6+)
- Yandex Games SDK

## 🚀 Запуск локально

```bash
python -m http.server 8080
# открыть http://localhost:8080
```

## 📁 Структура

```
src/
├── config.js
├── main.js
├── data/       ← мобы, миры и генераторы ботов
├── utils/      ← хелперы, звук, HiDPI рендеринг
├── components/ ← мёрдж-поле, бои, экономика, сохранение
└── scenes/     ← Phaser сцены (загрузка, поле, бестиарий, арена)
```
