# Minecraft Merge 🧱⚔️

Игра в жанре **Merge + Battle** для [Яндекс Игр](https://yandex.ru/games).

## 🎮 Описание

Объединяй мобов Майнкрафт, прокачивай армию и побеждай ботов в боях!

- **30 мобов** от Курицы до Дракона Края
- **Мёрдж-механика** — соединяй двух одинаковых → получаешь следующего
- **Система боёв** — выбирай до 3 бойцов, сражайся с ботами
- **Экономика** — изумруды, уровни, множители x1-x5
- **Бестиарий** — коллекция открытых мобов

## 🛠️ Технологии

- [Phaser 3.8](https://phaser.io/)
- Vanilla JavaScript
- Yandex Games SDK

## 🚀 Запуск локально

```bash
python -m http.server 8080
# открыть http://localhost:8080
```

## 📁 Структура

```
src/
├── config.js
├── main.js
├── data/       ← мобы и имена ботов
├── utils/      ← вспомогательные функции
├── components/ ← логика (мёрдж, бои, экономика)
└── scenes/     ← Phaser сцены
```
